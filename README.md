# customer-shopping-behavior-analysis
## 📊 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, sales trends, and factors that influence customer buying decisions.

The analysis was performed using **Excel, SQL, Python, and Power BI** to clean, analyze, visualize, and present meaningful insights from customer shopping data.

## 🎯 Objectives

* Analyze customer purchasing behavior
* Identify popular products and categories
* Understand customer preferences
* Analyze sales and purchase patterns
* Identify important customer segments
* Create interactive dashboards and visualizations
* Generate useful business insights from the data

## 🛠️ Tools & Technologies

* **Excel** – Data cleaning, formulas, Pivot Tables, and analysis
* **SQL** – Data querying and analysis
* **Python** – Data cleaning and exploratory data analysis
* **Pandas** – Data manipulation
* **Matplotlib / Seaborn** – Data visualization
* **Power BI** – Interactive dashboard and reporting
